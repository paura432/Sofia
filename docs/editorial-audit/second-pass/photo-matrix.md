# Matriz de fotografías

Cada fila corresponde a una **fotografía única** (no a cada aparición), revisada visualmente sobre la versión publicada (`public/media/…`, webp). Las copias se detectaron por firma perceptiva: las 46 fotos de los ensayos de Música, Calle, Estudio y Retrato son las mismas que las del archivo y comparten fila.

**Leyenda**
- *Estado*: E = ensayo de la ficha · A = archivo de 74 · S = «Serie completa» de la ficha · P = portada.
- *ALT plantilla*: las fotos que solo están en el archivo y en «Serie completa» reciben «{grupo}, imagen n» / «Serie completa n» / «{group}, image n» / «{группа}, изображение n».
- Ninguna fotografía tiene caption (el campo `caption` existe pero no se usa).
- *Artificial*: impresión de texto formulario o de relleno (Baja / Media / Alta), no de autoría.
- *Propuesta*: en ES. EN y RU se adaptarían después; vacía = conservar el ALT actual.
